## 一、怎么跑

零构建。起个静态服务器即可（也可以直接双击 `index.html`）：

```powershell
python -m http.server 8765 --bind 127.0.0.1 --directory <本目录>
# 浏览器打开 http://127.0.0.1:8765/
```

浏览器要求：支持 Canvas 2D 与 WebAudio 的现代桌面浏览器（Chrome / Edge / Firefox）。
首次点击任意键进入时会解锁 WebAudio（浏览器自动播放策略）。

## 二、玩法

**胜利条件**：摧毁敌方全部建筑与单位。左上角是你的基地，敌方在右下角。

| 系统 | 说明 |
| --- | --- |
| 经济 | 采矿车往返矿脉与精炼厂换钱；矿石会采空，得往远处找 |
| 电力 | 反应堆 +100 / 高级电站 +200；电力超支则生产与防御全部停摆（顶栏 POWER 变红） |
| 建造 | 底部建造栏 → 点建筑 → 拖到战场左键放置（靠近已有建筑会自动吸附对齐） |
| 生产 | 兵营出步兵、战车工厂出载具；生产建筑右键可设集结点 |
| 防御 | 防御碉堡（对步兵）、磁暴线圈（苏联·克装甲）、光棱塔（盟军·射程远） |
| 特殊能力 | 核弹 `N`（需 120 电力盈余，全图任意可见位置投放）、间谍卫星 `O`（全图视野 45 秒） |
| 阵营差异 | 苏联：动员兵便宜、犀牛坦克 700 HP、磁暴线圈、V3 远程拆家<br>盟军：大兵射程长、灰熊坦克快、光棱塔、多功能步兵车放风筝 |
| 难度 | 简单 / 普通 / 困难，影响 AI 经济与出兵规模、进攻时机 |

### 操作

| 操作 | 键位 |
| --- | --- |
| 选中 / 移动 / 攻击 | 左键点单位或地面；框选多个；`Shift` + 点追加 |
| 攻击移动 | `A` 然后点地面（边走边打） |
| 强制攻击 | `A` 然后点敌方目标 |
| 停止 | `S` |
| 编组 | `Ctrl+1~9` 编组，`1~9` 选组 |
| 修理 / 出售 | 按住 `Z` 点己方建筑修理；按住 `X` 点己方建筑出售（返还 50%） |
| 建造栏翻页 | `F2` 建筑 / `F3` 步兵 / `F4` 载具，或点左侧页签 |
| 快捷键建造 | 图标左上角的字母（如 `W` 反应堆、`T` 兵营、`X` 狂风坦克） |
| 视角 | 鼠标推边 / 方向键 / 点小地图 |
| 核弹 · 卫星 | `N` · `O` |
| 暂停 · 帮助 | `Esc` / `P` · `F1` |
| 音量 · 音乐 | `M` · `B` |

> 触屏只能做基础点击（合成鼠标事件）；完整操作以桌面鼠标为准。

## 三、目录

```
index.html        页面骨架
style.css         界面样式（军用绿面板风）
js/rules.js       数值与规则表（建筑 / 单位 / 特殊能力）
js/audio.js       WebAudio 程序合成音效 + 工业风 BGM（零素材）
js/engine.js      地图生成 / A* 寻路 / 战斗 / 战争迷雾 / 实体 / 采矿
js/ai.js          敌方 AI：运营 → 编队 → 波次进攻 → 回防
js/ui.js          建造栏 / 弹窗 / tooltip / 图标绘制（Canvas 简笔画）
js/main.js        主循环 / 渲染 / 输入 / 小地图
_verify/          端到端验证脚本与截图（playwright 驱动真浏览器）
```

## 四、验证记录

用 Playwright 驱动真实 Chrome 跑端到端（`_verify/check.py`），最近一次结果：

- 控制台错误 **0**；启动 → 选阵营 → 开局 → 建造放置 → 框选下令 → 造兵 → 进攻 → 结算全链路通过
- 主循环按真实帧推进（10s 墙钟 = 10.0s 游戏内时间）
- AI 运营链路：反应堆 → 精炼厂 → 兵营 → 战车工厂 → 防御 → 波次进攻，建筑会真正落地（曾因迷雾校验把 AI 挡在放置外，已修）
- 经济链路：采矿车往返卸矿正常（曾因卸矿判定半径小于建筑半对角线，矿车在厂外反复抖、经济归零，已修）
- 胜负两条分支都验证过：`MISSION ACCOMPLISHED` 与 `MISSION FAILED` 结算弹窗均正常
- 平衡实测（普通难度，脚本玩家）：AI 第一波 ≈ 200s 出动、≈ 260s 接触；挂机玩家约 4.8 分钟被推平；脚本玩家能打到 9 分钟互有攻防

复现：`python _verify/check.py`（需本机 Chrome + playwright，静态服务器跑在 8765）。
